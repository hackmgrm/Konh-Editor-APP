# 效率中心 0.4.0：实现与验收记录

目标是在空核编辑器内独立实现 Todofy 公开功能说明中的个人效率功能，并产出本机安装包。
未复制 Todofy 的受限源码、素材或界面。任务与生活日程独立于写作工作区。

## 安装包

`src-tauri/target/release/bundle/dmg/KonhEditor_0.4.0_aarch64.dmg`

同时生成 `src-tauri/target/release/bundle/macos/KonhEditor.app`。
DMG 校验与 app 的 `codesign --verify --deep --strict` 均通过。
SHA-256：`1ccb21a5aac41aacd937a31f7ad5872a127f816d8934c9241874ba0dfb66a7f9`。
最终安装包使用本地 ad-hoc 签名封装，未做 Apple 公证，未生成线上自动更新签名。

复现最终封装：先执行 `npm run app:build -- --bundles app,dmg`，再执行：

```sh
npm run tauri -- bundle --bundles app,dmg --config '{"bundle":{"createUpdaterArtifacts":false,"macOS":{"signingIdentity":"-"}}}'
```
